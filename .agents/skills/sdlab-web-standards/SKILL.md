# SD Kristen Satya Wacana Web Standards

## Core Principles
1. **No Dates on Activities**: Never add day/month/year to activity cards. Use thematic badges (Outdoor Learning, Outing Class, Edukasi Damkar, Mitigasi Bencana, Panggung Dongeng, Prestasi Siswa).
2. **Kak Kempo Context**: Always identify Kak Kempo as a national children's storyteller and literacy activist from Semarang (NOT martial arts).
3. **Hero Tagline**: "Membentuk Generasi Inovatif, Holistik, dan Berwawasan Global berdasarkan Kasih".
4. **Color Contrast & Legibility**:
   - Dark background / overlay: White headings (#ffffff), bright gold/orange numbers (#fd5f00 / #ffc107), light icons.
   - Light background: Slate navy headings (#1e293b), primary blue accents (#0d83ff), gray text (#475569).
5. **Equal Height Grid**: All cards (.staff, .course, .pricing-entry, .blog-entry) must be aligned with flexbox h-100 and fixed image aspect ratios.
